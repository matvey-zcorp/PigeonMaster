# Pigeon Master

## Описание
Игра Pigeon Master - Ловите голубей и прокачивайте своего голубя!

- Ловите голубей
- Прокаичвайте своего голубя
- Покупайте вашему голубя вещи

## Лицензия
Данная игра распрастраняется под лицензией MIT.
И является полностью бесплатной!
Исходный код открыт.

## Примечания
Игра находится в разработке!
На данный момент релизов не имеется.
Релиз планируется 1 февраля 2027 года.

## Системные требования
**ОС: Windows 7 и выше,**
**ОЗУ: 2ГБ и больше,**
**Дисковое пространство: 50МБ и выше**
**Процессор: Любой 32-битный процессор.**

На данный момент это примерные системные требования
Возможно они изменятся в будующем.

## Для разработчиков
**Используются библиотеки:**
**SDL3,**
**SDL Image,**
**SDL Mixer,**
**SDL TTF.**

main.cpp - Основной файл
build.bat - Запустите в консоли для компиляции
app.exe - Основной скомпилированный файл
debug.exe - Дебаг файл с выводом в консоль который не имеется у app.exe
